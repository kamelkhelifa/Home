Compiling and Running EVENT2 program

EVENT2 is a fortran program that computes the matrix-element squared and cross-section in e+e- annihilation at NLO (that is up to alpha_s^2) written by Mike Seymoure. It implements the Catani-Seymoure subtraction method to cancel divergencies and make numerical integration possible.

To compile and run the program:

  1. Download latest fortran code: event2_03.f. Download the GBOOK package; gbook.f (the updated version by Seymoure).
  2. You need to have gfortran compiler installed. If you haven't already then you can get the latest release from here.
  3. In a terminal window type: gfortran event2_03.f gbook.f. This will compile and run the code. If you get an error saying that IDATE has more arguments than should be be (or something similar) then you need to open gbook.f in a text editor and comment out the line that has the IDATE and ITIME calls
  4. You can change parameters, such as Center of Mass energy (EM), Number of Events (NEV), ...etc by opening the code in a text editor and edit it. Then compile and run as in step 3.

To run the program in Netbeans IDE then do the following:

  1. Download and install Netbeans. Make sure the chosen package includes C/C++ pack.
  2. Create a new project. File -> new project -> c/c++ project -> c/c++ application -> name it and choose directory -> finish
  3. Right-click "source files"-> new -> Fortran file. browse to where "gbook.f" and "event2_03" are located -> add
  4. project-> debug then project-> run main project. It should run and output a gtopdraw.top file.
  5. You can delete the "main.cc" file, created when setting "new project", as it isn't needed.

To open the "gtopdraw.top" file on a Mac or Linux OS then do:

  1. Download SLAC's topdrawer program (choose the binary version appropriate to your OS). Its's a .tar file.
  2. Untar the file somewhere in your computer. If using terminal then type: tar -xvf td_....tar; cd td_... (... are rest of the tar file's name).
  3. Place the executable file "td_..." into the directory where the "gtopdraw.top" file(s) is.
  4. For Mac: install the file libg2c.0.dylib, which is included in the tarball, in /usr/local/lib/ by typing in terminal
    [text-box color="green"]sudo cp libg2c.0.dylib /usr/local/lib/[/text-box]
  5. To create a .ps file from the .top file, type in the terminal
    [text-box color="green"] ./td_... gtopdraw.top "POSTSCR,ORIENT=3" [/text-box]

Linking EVENT2 with Fastjet

The guide below assumes that

  • EVENT2 files have been downloaded and compiled correctly. See this post.
  • FastJet has been downloaded and installed as instructed in the webpage.
  • The file "fastjet-config" is in "/usr/local/bin/". Otherwise replace the latter with the path in your computer where the file is.
  • NetBeans installed and running on your OS platform. Otherwise one can just use the terminal.

Setup EVENT2 to work with FastJet in NetBeans:

  1. First you need to create a new project: File -> New Project
    In the wizard that shows up, choose "C/C++ Development" and "C/C++ Application" (if these options are not available, you have not installed the C/C++ pack properly). Press next, name your project whatever you like, and press finish.
  2. In the "projects" menu to the left you should now see your newly created project.
    If it isn't bold; right-click it, and choose "set main project".
  3. Right-click project and choose "properties".
    In the properties screen you can "open" the submenues of the configuration properties by clicking the little icons at the left.
  4. In submenu Configuration Properties -> C/C++ -> C++ Compiler -> Command Line
    Add the following in "Additional options": `/usr/local/bin/fastjet-config --cxxflags`
  5. In submenu Configuration Properties -> Linker -> Tool : change g++ to gfortran.
  6. In submenu Configuration Properties -> Linker -> Command Line
    Add the following in "Additional options": `/user/local/bin/fastjet-config --libs --plugins` -lstdc++
  7. Exit properties by pressing "Apply" then "OK".
