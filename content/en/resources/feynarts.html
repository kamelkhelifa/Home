Installing FeynArts, FormCalc & LoopTools on Ubuntu and Mac:

There seems to be some installation & running issues with the automatic installer "FeynInstall" provided on the corresponding pages of all three codes [feynarts.de].

The best solution is to download and install each package separately and avoid using the "FeynInstall". This is particularly true for FormCalc package. One is strongly recommended to download and install FormCalc using "./compile" to avoid any errors while running "./configure" then "make" in the "process.fortran" folder created after running "process.m"

Otherwise one should create a directory in /usr/local/ and excute the "FeynInstall" from there.
