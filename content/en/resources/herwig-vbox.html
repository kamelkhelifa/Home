Installing and running Herwig on Mac OS

This post is a step-by-step guide for installing and running the HEP Mante Carlo program Herwig++ on Mac OS. The basic idea is that trying to install Herwig on a Mac, as instructed in the Herwig webpage, is a real headache. Herwig is originally setup to work under Linux systems. Thus it is better to have it to work under the latter. Therefore what one needs is to run a Linux OS on the Mac OS. This can be achieved through Virtualisation programs such as Virtual Box, Parallel desktop..etc.

So here are the steps :

1. Download and install Virtual Box (it's a free open source program).

2. Download Ubuntu, or any other Linux distribution but this is recommended for those who are new to Linux systems. Follow the instructions on Virtual Box's website on how to install a new OS.

3. Follow the instructions on the Herwig wiki page.

This way is far better, time-saving and more efficient for installing Herwig++ on your machine than trying to dig out how to install it straight onto the Mac OS.

4. For data analysis and plotting one may use Rivet. Installation instructions under Linux OS can be fund in its webpage.
