الطريقة القديمة (المتجاوَزة) لتثبيت Herwig وتشغيله (هنا)

الطريقة الجديدة: بواسطة Docker [انظر الدرس التطبيقي لبرنامج Herwig في مدرسة MCnet 2019]

لا حاجة إلى تثبيت Herwig على جهازك الخاص إذا استعملت صورة docker الافتراضية المتوفرة (انظر القسم التالي). أما إذا كنت تنوي استعمال Herwig في أبحاثك الخاصة بعد مدرسة MCnet، فقد تفيدك التعليمات الواردة في صفحة التثبيت.

ستتعلم خلال هذا الدرس التطبيقي:

كيفية محاكاة أحداث LEP
كيفية محاكاة أحداث LHC
كيفية إدراج تحليلات rivet ومقارنة المحاكاة بالبيانات
كيفية تفعيل أجزاء مولّد الأحداث وتعطيلها
كيفية تعديل وسائط وابل البارتونات (Parton shower) ونموذج التهدرن (Hadronization)
معالج الأحداث Les Houches

قبل أن تبدأ (حاويات docker)

يمكن إنجاز جميع التمارين الواردة في هذا الدرس التطبيقي باستعمال صورة docker المتوفرة لبرنامج Herwig.
وإذا لم تكن قد ثبّتّ docker بعد، فاتبع التعليمات الواردة في موقع docker وثبّته على حاسوبك الشخصي.

يمكن سحب حاويات docker المطلوبة مباشرة من dockerhub بالأمر

docker pull hepstore/rivet-herwig

Remember Linux users: sudo docker

هذا كل ما في الأمر! ولتشغيل Herwig نفّذ أمر الصدفة الآتي

docker run -i  --rm  -u `id -u $USER`:`id -g`  -v $PWD:$PWD -w $PWD  hepstore/rivet-herwig Herwig

(تحديث: مع أحدث صورة docker لـ hepstore/rivet-herwig نفّذ)

docker run -it -u $(id -u $USER) -v $PWD:$PWD -w $PWD hepstore/rivet-herwig /herwig/bin/Herwig

يتيح هذا للحاوية الوصول إلى ملفاتك المحلية وكتابة الملفات في مجلد العمل الحالي.

كما يمكنك إنشاء اسم مستعار (alias) بالأمر

alias Herwig='docker run -i  --rm  -u `id -u $USER`:`id -g`  -v $PWD:$PWD -w $PWD  hepstore/rivet-herwig Herwig'

والآن، كل ما عليك فعله لتشغيل Herwig هو تنفيذ

Herwig

في الطرفية.

ونوصي أيضًا بإنشاء اسم مستعار لأمر rivet rivet-mkhtml

alias rivet-mkhtml='docker run -i  --rm  -u `id -u $USER`:`id -g`  -v $PWD:$PWD -w $PWD  hepstore/rivet-herwig rivet-mkhtml'

إذا نجح ذلك، فأنت جاهز لبدء الدرس التطبيقي بـالتشغيل الأول: LEP. وإن واجهتك أي مشكلة، فتحدّث إلى أحد المؤطرين.

التعليمات:

  1. التثبيت
  2. التشغيل الأول: LEP
  3. التشغيل الثاني: إنتاج Z والنفاثات في LHC
  4. (متقدم) التشغيل الثالث: أحداث الانحياز الأدنى (minimum bias) والفيزياء اللينة
  5. (متقدم) معالج الأحداث Les Houches
